# Høstløpet 2026 - påmeldingsskjema

En enkel nettside der løpere kan melde seg på et lokalt løp, enten 5, 10 eller 15 km. 
Prosjektoppgave i Programvareutvikling 2. 

## Kjør prosjektet

Åpne `index.html` i en nettleser. Ingen installasjon trengs. 

## Filer

- `index.html` - Skjema, kvittering og deltakerliste
- `style.css` - design
- `logic.js` - reglene for påmelding
- `script.js` - leser skjemaet, lagrer og viser resultat

## Teknologier

HTML, CSS, JavaScript og localStorage

Påmeldingene lagres bare i nettleseren. Mer om valg og testing, samt begrensninger står i dokumentasjonen.
